        Resultado completo

          Como funcionam os links

          O resultado de cada pessoa vai dentro do próprio link, depois do #, embaralhado para ninguém ler sem querer. Essa parte do endereço não é enviada para servidor nenhum e não há banco de dados: a lista fica salva só neste navegador.

          Importante: o embaralhamento evita espiadas acidentais, mas não é criptografia. Quem souber decodificar consegue ler o conteúdo de um link, então quem organiza não deve abrir os links dos outros.
